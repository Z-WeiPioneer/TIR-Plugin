# docs/ — 项目文档目录（占位）

> P0 启动基线阶段，正式文档位于启动基线包 `P0_启动基线/docs/`（环境与许可矩阵、ADR、风险与决策日志、P0 验收清单）。本目录用于初始化 Git 仓库后承载**随代码维护**的文档。

计划收录：

- `架构.md`：分层（Core / UI / LT 桥 / SW 桥）与线程/COM 模型
- `数据契约.md`：TargetModel、design.json / target_curve.csv / profile.csv 的 JSON Schema
- `ADR/`：架构决策记录（运行时、COM 与线程、构建与 CI 等）
- `验收/`：验收指标与黄金案例说明
- `用户手册/`：安装、许可、使用与故障排查

约定：文档使用中文、UTF-8；所有命令与结论必须注明是否在本机验证；未验证项写"本机未验证"。
